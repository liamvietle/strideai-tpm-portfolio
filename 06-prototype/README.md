# StrideAI Prototype

## Confidence & Adaptation Engine

This prototype implements a simplified version of the StrideAI adaptive coaching decision framework described in the architecture and AI evaluation artifacts.

The prototype demonstrates:

- fatigue classification
- confidence-based autonomy
- weather-aware adaptation
- deterministic safety rules
- insufficient-data handling
- auditable decision outputs

This is a portfolio prototype, not a production coaching system.

Runner Signals
