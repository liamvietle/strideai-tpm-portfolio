# GitHub Setup — Beginner Guide

## 1. Create your GitHub account

Go to https://github.com and create/sign in to your account.

Use a professional username if possible because it may appear on your resume.

## 2. Create the repository

After signing in:

1. Click the **+** button in the top-right.
2. Select **New repository**.
3. Repository name: `strideai-tpm-portfolio`
4. Description:
   `AI Technical Program Management portfolio case study covering product strategy, architecture, execution, AI evaluation, risk management, and launch governance.`
5. Select **Public**.
6. Do **not** add a README — we already have one.
7. Click **Create repository**.

## 3. Upload the files — easiest method

On the new repository page:

1. Click **Add file**.
2. Select **Upload files**.
3. Open the downloaded ZIP on your computer and extract it.
4. Select all folders/files inside the extracted `strideai-github-ready` folder.
5. Drag them into the GitHub upload area.
6. Scroll down.
7. In the commit message box, type:
   `Initial StrideAI portfolio`
8. Click **Commit changes**.

GitHub will then publish the files.

## 4. Check the README

Return to the repository home page.

You should see the StrideAI README rendered automatically.

Check:
- The title appears correctly.
- The architecture image appears.
- The rollout image appears.
- The folders are visible.
- The links work.

## 5. Pin the repository

Go to your GitHub profile.

Choose **Customize your pins** and select `strideai-tpm-portfolio`.

This makes it visible near the top of your profile.

## 6. Add it to your resume

Use a short entry such as:

**StrideAI — AI Adaptive Running Coach | Technical Program Management Case Study**

Designed an end-to-end AI program covering adaptive coaching architecture, ML/LLM decision boundaries, MVP prioritization, Jira execution planning, RAID management, AI quality gates, controlled rollout and executive risk communication.

Then add the GitHub repository link.

## 7. Important credibility rule

Describe StrideAI as a **portfolio case study / simulation**.

Do not describe it as:
- a product you launched
- a company you founded
- a production system you operated
- a project from a previous employer

The value of the project is demonstrating how you think and operate as a TPM.

## 8. Recommended GitHub profile

After publishing StrideAI, add a short profile bio such as:

`Technical Program Manager | Cross-functional programs | AI, technology & operations | Building practical technical depth`

Then pin StrideAI.
